# logic — Personal Odyssey

## Direction contract

THESIS：个人网站是一段可以选择的旅程，作品与生活逐幕出现。
OWN-WORLD：保留白色雕塑封面；后续使用夜蓝候车空间、石白纸票、冷银雕塑与细线轨道。中心 logic 是跨场景身份锚点。
STORY：触碰飞鸟进入，撕下一张单程票，穿过横向车窗式过渡，在环形展台选择章节。快速目录允许面试官直达作品与经历。
FIRST VIEWPORT：第一屏仍为原来的雕塑封面。候车幕上方短标题，中间斜体 logic，下方纸票；不同时显示章节正文。
FORM：分幕式个人展览；沿用用户指定交互与已有视觉基础，未运行随机方向选择（seed: none）。
FINISH：已进行桌面、移动端、减少动态效果、实际拖撕、旋转、翻牌、shader 与返回检查；结果保存在 outputs/journey-checks.json。

## 页面与组件

雕塑封面 → 单程票 → 发车过渡 → 中转站 → 四个章节。

- 作品实验室：网站本身为第一件真实展示，其余项目留待填写。
- 成长档案：学习、实习、生活三个资料槽，没有虚构日期或经历。
- 偏爱收藏：Cry for Me、Take Me Hand、火影忍者、炉石传说；逐张翻牌。
- 关于与联系：介绍、能力、联系方式槽；DitherVeil 探索插画。

旅程状态与页面拼装在 src/journey/journey.js，内容在 chapters.js，样式在 journey.css。每个场景只挂载自己的组件。返回保留封面交互，退出销毁当前组件。全站目录是按需打开的补充路径。

## 视觉参数

夜蓝 #0a1c2a；纸白 #e9e7dc；辅助文本 #a5b4bd。主标题使用系统中文字体，英文 identity 保留 Georgia italic。平常过渡 0.7 秒；发车 1.65 秒；RefineFrame 每级 75 毫秒。运动以原组件物理模型为主，不重复叠加另一套变换。

桌面保持单屏布景。手机保留候车和中转单屏；章节正文允许内部纵向阅读。始终保留返回。减少动态效果下省略发车位移与弹性，保留操作结果。导航不使用 DodgeField。

## 素材来源

public/chapters 的 4 张 PNG 是本轮用 Three.js 程序化模型与光照渲染的原创抽象雕塑插画，不是用户照片，也不冒充真实项目截图。重渲染入口 tools/art-studio.js；没有采用 React Bits 的示例照片。原封面的模型、纹理和字体保持既有来源状态，详情沿用先前素材审计。

## 当前边界

这是一版可运行的完整浏览框架。真实简历、项目详情、联系地址、音乐播放音源尚未提供；没有伪造表单提交、音乐播放器或外部链接。React Bits 为源码宿主适配，详见组件 README。未发布到公网。
